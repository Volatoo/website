# Volatoo website

Source for the official Volatoo public website, end-user handbook, and release
portal.

## Owns

- the project homepage and product explanation;
- installation, persistence, update, rollback, and troubleshooting guides;
- presentation of published releases, checksums, and supported targets;
- website build, accessibility, redirects, and deployment configuration.

## Does not own

- operating-system implementation or architecture contracts, which live in
  [Volatoo/Volatoo](https://github.com/Volatoo/Volatoo);
- release images and packages, which are published as signed artifacts;
- canonical logos and design source files, which live in
  [Volatoo/artwork](https://github.com/Volatoo/artwork).

The repository is intentionally a scaffold until the first public release site
is implemented.
